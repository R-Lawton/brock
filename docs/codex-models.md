# Codex models

Brock does not require a particular model. These are the models available in the
current Codex account, with `gpt-5.6-luna` as the default:

| Model | Intended use |
| --- | --- |
| `gpt-5.6-sol` | Latest frontier agentic coding model |
| `gpt-5.6-terra` | Balanced agentic coding for everyday work |
| `gpt-5.6-luna` | Fast, affordable agentic coding (default) |
| `gpt-5.5` | Complex coding, research, and real-world work |
| `gpt-5.2` | Professional work and long-running agents |

Choose a model per session when needed:

```bash
codex -m gpt-5.6-sol
codex -m gpt-5.6-terra
codex -m gpt-5.6-luna
codex -m gpt-5.5
codex -m gpt-5.2
```
